Agent Browser Bridge

Agent Browser Bridge

Let Claude Code, Cursor or any MCP agent use the browser you’re already in, with your real tabs and logins. It can tidy your tabs, dig through history and bookmarks, and click around pages, and you can chat to it from Chrome’s side panel. Works with Chrome and Safari.

JumpAround

JumpAround

Chrome’s tab bar gives up at about twenty tabs. JumpAround gives you ⌘ K and fuzzy search instead, the same as the jump box on this page. Type a few letters, press Enter, and you’re there.
